## 2. 視覺方向

| | 方案 A：白天聚落・品牌延伸（**已採用**） | 方案 B：夜晚劇場 |
|---|---|---|
| 底色 | #f2f2f2（網站白天底） | #0e1118（網站夜晚底） |
| 強調色 | 品牌橘 #fb5b1a | 品牌橘＋窗燈暖白 |
| 字體 | Lexend Exa（Logo／英文大標）＋ Noto Sans TC | 同左 |
| 版面 | 內頁白底、圓角 12 卡片，跟網站卡片一致；封面與結尾用夜晚城市滿版 | 全部深色、滿版截圖、電影感 |
| 優點 | 截圖大多是白天畫面，放在淺底最清楚；投影機上也亮 | 氣氛強、有記憶點 |
| 缺點 | 比較安全 | 白天截圖放在深底很跳；投影時暗部容易糊 |

**推薦 A：** 簡報本身就是網站設計系統的延伸，客戶看完簡報再切到網站不會有落差。
